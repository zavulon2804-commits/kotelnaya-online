# Заметки для Claude

- Сайт: https://kotelnaya.online, GitHub Pages из ветки `main`, корень репозитория. Домен куплен на reg.ru, файл `CNAME` не удалять.
- Весь конструктор — один `index.html` (HTML + CSS + JS, без сборки и зависимостей; шрифты с Google Fonts).
- Публикация: закоммитить изменения в `main` и запушить — Pages обновляет сайт примерно за минуту.
- Та же страница опубликована как артефакт claude.ai: https://claude.ai/artifact/CsJRCg7vYQCQ53Dm47ggm8. В артефакте нет `<!doctype>/<head>/<body>` (их добавляет обёртка), а кнопка «Скачать PNG» скрыта внутри iframe. Если обновляешь артефакт, убери обёртку документа.
- Данные схемы хранятся в localStorage под ключом `kotelnaya-v2`. При несовместимом изменении формата меняй ключ.
- Книга «Паспорт котельной» и наклейки содержат QR-код на https://kotelnaya.online — адрес менять нельзя.
- Владелец — монтажник котельных, общается по-русски, не программист: объяснять простыми словами.
