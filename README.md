# kotelnaya.online

Онлайн-конструктор схемы котельной: котлы, бойлеры, гидрострелки, насосные группы, трубы по цветам, номера узлов для наклеек, спецификация и штамп. 8 готовых шаблонов.

Сайт: https://kotelnaya.online

Весь сайт — один файл `index.html` без сборки. Публикуется через GitHub Pages из ветки `main`.
